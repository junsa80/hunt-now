# 몬헌 나우 대비 차이 목록 (v3 → v4)

조사 출처: Niantic 도움말 "Perfect evade"·"[TIPS] Slay Monster", monsterhunternow.com "Slaying Monsters", Game8 "Weapon Controls and Combat Tips".
확인한 몬헌 나우 핵심: 공격 직전 몬스터가 **붉게 빛남**(바닥 표시 아님), 그 순간 플릭 회피 → 슬로모션 + **노란 윤곽** + 다음 공격 강화(완벽 회피),
데미지 숫자 색으로 약점(노랑 계열)·속성+약점(빨강) 구분, 부위를 노려 **넘어뜨리기(다운)** 가능, 정면을 피하고 측면·후방을 노리라는 위치 싸움, 특수기 게이지·무적.

## 아직 남은 차이 (정직하게)
- 진짜 블룸 후처리는 넣지 않음(가산 스프라이트로 대체). 휴대폰 성능 확인 전이라 보류.
- 캐릭터는 여전히 절차적 도형 조합(리깅된 실제 모델 아님). 얼굴·머리결은 개선했지만 몬헌 나우 수준 모델과는 차이 큼.
- 실제 폰에서의 손맛·프레임은 미검증. 헤드리스(소프트웨어 렌더)에서는 자동 화질이 '낮음'까지 내려감.
- 몬헌 나우에는 몬스터 체력바가 없음. 우리는 가독성 기준(공통 설계 기준)에 따라 유지.
