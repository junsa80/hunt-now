# 헌트 나우: 정화의 사냥꾼

몬스터 헌터 나우의 터치 전투 감각을 참고해 만든 **모바일 브라우저용 싱글 플레이 3D 액션 사냥 게임** 프로토타입입니다.
플레이: https://junsa80.github.io/hunt-now/ (**세로 화면 기본**, 가로도 지## 조작 (몬스터 헌터 나우 방식)
- **드래그 = 이동**: 화면 어디서든 손가락을 대고 끌면 그 자리에 스틱이 생기고, 손가락을 따라옴 (카메라 기준)
- **탭 = 공격**: 연타하면 무기별 콤보. 입력 버퍼 0.35초라 공격 중 미리 눌러도 다음 타로 이어짐
- **휙 밀기(플릭) = 그 방향으로 회피**: 무적 시간 있음. 공격 후딜·차지·가드 중에도 회피로 끊을 수 있음. 맞기 직전에 피하면 **완벽 회피**(슬로·번쩍) → 다음 공격 치명타
- **길게 누르기 = 무기 홀드 동작** (아래 표). 누른 채 끌면 천천히 이동
- 두 손가락: 한 손가락으로 이동하면서 다른 손가락으로 탭·홀드 가능
- **특수기 버튼**(오른쪽 아래 원형 게이지): 공격·완벽 회피·저스트 가드로 차오르고, 100%면 탭해서 발동. 발동 중 무적
- **타겟**: 몬스터가 둘일 때 락온 대상 변경. 평소엔 가장 가까운 몬스터를 자동 조준하고, 카메라는 헌터 어깨 너머에서 몬스터를 바라봄
- 몬스터가 **붉게 빛나고** 바닥에 붉은 범위가 차오르면 공격이 옴
- 설정: 회피 버튼 표시(기본 끔), 조작 안내 표시
- PC 테스트: WASD 이동 / J 탭·길게 / K·Space 회피 / U 특수기 / L 타겟

### 무기 7종
| 무기 | 탭 | 길게 누르기 | 특수기 |
|---|---|---|---|
| 한손검 | 빠른 4연속 | 방패 가드(직전 가드=저스트 가드→반격 찬스), 가드 중 탭=방패 치기 | 퍼펙트 러시 |
| 대검 | 묵직한 3연속 | 모아베기 3단계 | 참 모아베기 |
| 태도 | 긴 사거리 3연속, 맞히면 기력 게이지↑ | 기인 베기(기력 25 소모, 기력 단계 백→황→적, 단계당 공격 +10%) | 기인 투구 가르기 |
| 쌍검 | 매우 빠른 5연속(한 번에 2타) | 귀인 난무(누르는 동안 연속 베기, 최대 2초) | 천상의 칼춤 |
| 해머 | 3연속 내려치기 | 모으기 3단계(3단계=회전), 머리 부위 타격 시 기절 누적 | 빅뱅 러시 |
| 랜스 | 3연속 찌르기 | 대방패 가드(피해 85% 감소), 가드 성공 직후 손 떼면 카운터 ×2.8 | 돌격 찌르기 |
| 활 | 원거리 속사 | 모아 쏘기 3단계(3단계=3갈래) | 용의 일격(관통) |

모든 무기에 무속성 기본형이 있고, 대장간에서 화염·빙결·번개·수류 속성판을 제작·강화할 수 있음. 무기마다 외형 모델이 다름(방패, 대형 검, 태도, 쌍검, 망치, 랜스+대방패, 활).

## 전투
- 바닥의 붉은 범위(원·부채꼴·직선·고리)가 차오르다가 노랗게 되면 공격이 들어옴, 몬스터도 예비 동작을 함
- 몬스터 6종:
  - 화염 늑대 루가: 돌진·물기·화염 숨결·3연 돌진
  - 빙결 마녀 셀레스: 얼음 기둥·서리·빙우·노바 (거리를 둠)
  - 뇌룡 기사 드라카: 내려찍기·도약·지진파·번개
  - 수류 인어 마리나(신규, 수류, 약점 번개): 파도·물방울·소용돌이·해일 (거리를 둠)
  - 여우불 무녀 코하쿠(신규, 화염, 약점 수류): 여우불·순간이동 강습·부채꼴 화염·화염 기둥
  - 폭풍 하피 실피(신규, 번개, 약점 빙결): 급강하·돌풍·깃털 비·폭풍
- 신규 3종은 2D 그림이 없어서, 도감과 카드에 3D 모델을 찍은 초상화를 씀
- 레벨이 오를수록 체력·피해가 늘고 패턴이 추가되며 예비 동작이 짧아짐
- 부위 파괴(뿔·꼬리·날개·얼음 관): 파괴 시 경직, 외형 변화, 추가 소재. 노란 빛은 약점 부위
- 속성(화염·빙결·번개·수류)과 상태 이상(화상·빙결·마비·수속성 약화), 약점 속성은 피해 +35%
- 데미지 숫자, 히트스톱, 화면 흔들림, 진동, 베기 궤적
- 전투 중에는 아이템이나 정화 버튼 없이 순수 액션만

## 진행
마을(사냥감 선택·대장간·동료·도감·설정) → 사냥(최대 동료 3명) → 결과(소재·정화 판정)
- 정화 점수는 전투 결과로만 계산함: 남은 시간 20 + 남은 체력 20 + 부위 파괴 30 + 피격 횟수 15 + 속성 상성 15
- **정화 조건(어려워짐)**: 점수 70점 이상, 몬스터 Lv2 이상, 부위 파괴 1곳 이상, 아직 동료가 아닌 종
- **같은 종 동료는 한 명만** 둘 수 있음. 이미 동료인 종을 토벌하면 정화 대신 보너스 소재를 줌
- 정화하면 이름·머리색·장식이 정해진 개체가 합류하고, 종마다 2개 역할 중 하나를 고름
- 역할: 딜러 / 탱커(도발·가드) / 힐러 / 버퍼(공격력↑) / 디버퍼(받는 피해↑·둔화). 종 특성 계승: 늑대=공격 속도, 마녀=빙결 축적, 뇌룡=피해 감소, 인어=자동 회복, 여우=화상 축적, 하피=속도
- 동료 잠재력은 정화한 몬스터 레벨과 점수에 비례하고, 플레이어가 만든 무기를 공유 장착할 수 있음
- 실패해도 경험치와 일부 소재를 얻음

## 저장
- 자동 저장(localStorage, 형식 버전 v3 + 이전 버전 이관). v2→v3 이관 때 같은 종 중복 동료는 가장 강한 한 명(레벨·잠재력 기준)만 남기고, 나머지는 한 명당 가죽 3개 + 부위 소재 2개로 바꾸고 마을 화면에 알림을 띄움. 없는 무기 종류도 자동 추가됨
- **이 기기에만 저장되고 클라우드 동기화는 없음.** 설정 탭에서 JSON 백업 내보내기·가져오기를 할 수 있고, 더 최신 기록을 덮어쓰려 하면 경고가 뜸
- 효과음·진동·화면 흔들림은 켜고 끌 수 있음
- PWA: 홈 화면에 추가할 수 있고 오프라인 캐시 지원

## 기술
순수 HTML/CSS/JS + Three.js r160(`vendor/`에 포함). 캐릭터는 3D 모델 파일 없이 코드로 생성함(툰 셰이딩, 외곽선, 관절 계층, 절차적 애니메이션).
- `chars.js` 캐릭터 생성·애니메이션 / `data.js` 몬스터·무기·대사 / `main.js` 전투·AI·UI·저장 / `sw.js` 오프라인

## 검증
`test/touch-v2.js`: 헤드리스 크로미움에서 터치를 흉내 내 자동 검증함 (390×844 세로, 844×390 가로). 드래그 이동, 탭 공격·콤보, 플릭 회피, 공격 중 회피 캔슬, 두 손가락 조작, 무기 7종의 탭·홀드·특수기, 정화 조건, 중복 차단, v2 저장 이관, JS 오류를 확인함.
헤드리스에서는 터치 명령 하나에 약 150ms 지연이 생겨서, 빠른 탭·플릭은 페이지 안에서 시간 간격을 맞춘 TouchEvent로 보내고, 홀드와 버튼은 CDP 터치를 씀. **실제 폰에서 손으로 해 본 조작감·프레임률은 이 검증에 포함되지 않음.**
실행: `python3 -m http.server 18923` 다음에 `NODE_PATH=<puppeteer-core 경로> URL=http://127.0.0.1:18923/ node test/touch-v2.js`
