# 헌트 나우: 정화의 사냥꾼

몬스터 헌터 나우의 터치 전투 감각을 참고해 만든 **모바일 브라우저용 싱글 플레이 3D 액션 사냥 게임** 프로토타입입니다.
플레이: https://junsa80.github.io/hunt-now/ (가로 화면 추천, 세로도 지원)

## 조작
- 왼쪽 화면 드래그: 가상 조이스틱 이동 (카메라 기준)
- **공격** 탭: 연속 공격 (한손검 4연타 / 대검 3연타), 공격 중 다시 누르면 다음 타로 연결
- **공격** 길게: 차지. 버튼 둘레의 노란 링이 단계별로 차고, 손을 떼면 차지 공격 (한손검 2단계 / 대검 3단계)
- **회피**: 구르기, 무적 시간 있음. 공격이 들어오기 직전에 피하면 **완벽 회피**(화면 번쩍, 슬로모션) 후 **반격 찬스**(다음 공격 치명타·빨라짐)
- **타겟 전환**: 몬스터가 둘일 때 락온 대상 변경. 평소에는 가장 가까운 몬스터를 자동 락온
- PC 테스트: WASD 이동 / J 공격(길게=차지) / K·Space 회피 / L 타겟

## 전투
- 바닥의 붉은 범위(원·부채꼴·직선·고리)가 차오르다가 노랗게 되면 공격이 들어옴, 몬스터도 예비 동작을 함
- 몬스터 3종: 화염 늑대 루가(돌진·물기·화염 숨결), 빙결 마녀 셀레스(원거리 얼음 기둥·서리·빙우·노바), 뇌룡 기사 드라카(내려찍기·도약·지진파·번개)
- 레벨이 오를수록 체력·피해가 늘고 패턴이 추가되며 예비 동작이 짧아짐
- 부위 파괴(뿔·꼬리·날개·얼음 관): 파괴 시 경직, 외형 변화, 추가 소재. 노란 빛은 약점 부위
- 속성(화염·빙결·번개)과 상태 이상(화상·빙결·마비), 약점 속성은 피해 +35%
- 데미지 숫자, 히트스톱, 화면 흔들림, 진동, 베기 궤적
- 전투 중에는 아이템이나 정화 버튼 없이 순수 액션만

## 진행
마을(사냥감 선택·대장간·동료·도감·설정) → 사냥(최대 동료 3명) → 결과(소재·정화 판정)
- 정화 점수는 전투 결과로만 계산함: 남은 시간 20 + 남은 체력 20 + 부위 파괴 30 + 피격 횟수 15 + 속성 상성 15, 기준 55점
- 정화하면 같은 외형에 이름·머리색·장식이 다른 별개 개체가 동료로 합류하고, 종마다 2개 역할 중 하나를 고름
- 역할: 딜러 / 탱커(도발·가드) / 힐러 / 버퍼(공격력↑) / 디버퍼(받는 피해↑·둔화). 종 특성 계승: 늑대=공격 속도, 마녀=빙결 축적, 뇌룡=피해 감소
- 동료 잠재력은 정화한 몬스터 레벨과 점수에 비례하고, 플레이어가 만든 무기를 공유 장착할 수 있음
- 실패해도 경험치와 일부 소재를 얻음

## 저장
- 자동 저장(localStorage, 형식 버전 v2 + 이전 버전 이관)
- **이 기기에만 저장되고 클라우드 동기화는 없음.** 설정 탭에서 JSON 백업 내보내기·가져오기를 할 수 있고, 더 최신 기록을 덮어쓰려 하면 경고가 뜸
- 효과음·진동·화면 흔들림은 켜고 끌 수 있음
- PWA: 홈 화면에 추가할 수 있고 오프라인 캐시 지원

## 기술
순수 HTML/CSS/JS + Three.js r160(`vendor/`에 포함). 캐릭터는 3D 모델 파일 없이 코드로 생성함(툰 셰이딩, 외곽선, 관절 계층, 절차적 애니메이션).
- `chars.js` 캐릭터 생성·애니메이션 / `data.js` 몬스터·무기·대사 / `main.js` 전투·AI·UI·저장 / `sw.js` 오프라인
